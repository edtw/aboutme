Micro Runtime executa IA localmente.

Runtime modular em Rust para ambientes restritos. Esta página mostra só ideias seguras: como a saída numérica vira ações limitadas, como modelos minúsculos respeitam orçamentos, como envelopes mantêm artefatos canônicos.

01

Plano de decisão, não piloto automático

Um trait mínimo TokenEngine retorna tokens numéricos. Uma ponte mapeia tokens do modelo para tokens de dispatch, e um dispatcher fixo de 256 slots one-shot invoca um handler HostOp fechado. Saída probabilística nunca vira autoridade ambiente.

trait TokenEngine {
  fn infer_next_token(&self, input: &[u32]) -> u32;
  fn reset(&mut self);
}
// bridge: model_token -> dispatch_token -> HostOp
// dispatcher: one-shot, fixed 256 slots, closed enum
02

GGUF local, explícito e previsível

Carregamento via mmap ou totalmente em memória (sem escrita em disco), modelos quantizados Qwen/Llama/Gemma/Phi em CPU, resolução explícita sem fallback silencioso, decodificação restrita a vocabulário de dígitos e buffers zerados no drop.

MICRO_RUNTIME_GGUF=/models/qwen3-0.6b-q4_k_m.gguf
# missing model => None (no silent fallback)
# think budget default 2048, act budget 32 digits
03

M35 TinyML VM

Header canônico de 64 bytes, opcodes de tamanho fixo (FC_W8A8, ADD_RQ, LUT8, ARGMAX, END), validação completa da tape (spans, aliasing, quantização, ordem, orçamentos), apenas int8, sem heap, sem float, sem grafo. Assembler e trainer offline geram imagens byte-idênticas com manifests SHA; publicamente, apenas fixtures sintéticas.

MAGIC M35\0 · VERSION 1 · HEADER 64B
MAX_OPS 4096 · MAX_ARENA 16MiB · budgets enforced
tape: ARGMAX penultimate, END last
04

MRE1 envelopes

Header de 144 bytes + até 256 registros de 80 bytes + trailer de 104 bytes. Ordem canônica, tamanhos, campos zero-reserved e regras cruzadas de autoridade. Views emprestadas zero-copy; confiança (assinaturas, contadores) fica no bootstrap, nunca no parser.

05

Disciplina de memória

Alocador global customizado com páginas de 4 KiB, heap fragmentado e escopos efêmeros; maps somente leitura sem follow; dispatch one-shot que limpa buffers. O CI impõe formatação, inventário de arquitetura, testes e limites de tamanho.

06

O que fica deliberadamente de fora

Sem pesos, chaves, certificados, transportes, mixnet, kernel, drivers, C2 ou evasão. Sem código privado. Esta demonstração é uma explicação original de conceitos públicos, não um release do runtime privado.

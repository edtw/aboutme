SANITIZADO / NIVEL DE ARQUITETURA

Micro Runtime executa IA com limites rigidos.

Runtime modular em Rust para ambientes restritos. Saída numérica de modelos vira ações limitadas, modelos pequenos respeitam orçamentos declarados e parsers de artefatos ficam separados das decisões de confiança.

01 / AUTHORITY

Plano de decisão, não piloto automático

Um TokenEngine mínimo retorna tokens numéricos. Uma ponte mapeia tokens do modelo para tokens de dispatch, e um dispatcher fixo one-shot invoca um handler HostOp fechado. Saída probabilística nunca recebe autoridade ambiente.

model_token -> dispatch_token -> HostOp
dispatcher: one-shot / 256 slots / closed enum
02 / LOCAL MODEL

Resolução explícita de modelo

Carregamento via mmap ou em memória, inferência quantizada em CPU, decodificação restrita e nenhum fallback silencioso quando falta um modelo.

MODEL=/models/local.gguf
missing model => None
act budget => 32 digits
03 / TINYML

M35 VM

Um header canônico e opcodes de tamanho fixo são validados integralmente antes da execução. A VM usa operações int8, sem heap, sem ponto flutuante e com limites rígidos para operações e arena.

HEADER 64B / MAX_OPS 4096
MAX_ARENA 16MiB / END required
04 / FORMAT

MRE1 envelopes

Ordem canonica, registros limitados, campos reservados e views zero-copy. Confianca em assinaturas e contadores fica no bootstrap, nao no parser.

05 / MEMORY

Disciplina de memória

Alocador baseado em páginas, heap fragmentado, escopos efêmeros, maps somente leitura e limpeza de buffers tornam decisões de recurso e lifetime visíveis.

06 / PUBLIC BOUNDARY

Deliberadamente excluído

Sem pesos, chaves, certificados, código privado, transportes, kernel, infraestrutura de comando ou material de evasão. Esta é uma explicação original de conceitos seguros, não um release do runtime.

01Estudo de caso privado

RUST · SISTEMAS DISTRIBUÍDOS · MESH / BLOCKCHAIN / COMPUTE · Spirix

Karma Network

Framework de rede mesh em Rust com blockchain Proof of Antiquity, computação distribuída e capacidades de agentes. Três camadas: blockchain (consenso PoA, carteiras Ed25519, atestação de hardware, nullifiers anti-Sybil, marketplace on-chain, defesa contra eclipse), rede mesh (overlay DHT, roteamento mesh, relay, sincronização de estado via DAG, descoberta de pares) e computação distribuída (aprendizado federado com FedAvg/DiLoCo, agregação segura, privacidade diferencial, inferência ML em Rust puro com Candle, coordenação em enxame). Chameleon é a implementação de agente de referência sobre o Karma.

Desafio
Unificar consenso, rede e ML distribuído em um único workspace Rust sem perder operabilidade.
Evidências
Rust 2024 workspace · Tokio · Axum · SQLx/PostgreSQL · Candle · DHT/mesh · PoA chain · Docker
02Estudo de caso privado

RUST · ENGENHARIA DE SISTEMAS · RUNTIME LOCAL DE IA

Micro Runtime

Runtime modular em Rust 2021 para ambientes restritos. Arquitetura por features com no_std opcional, alocador customizado (páginas de 4 KiB, heap fragmentado, escopos efêmeros), SecureDispatcher fixo de 256 slots one-shot, IO com memory-map somente leitura, ISA fechada HostOp com session workers e validação automatizada da arquitetura no CI. Execução local de IA: trait TokenEngine separando decisões numéricas de ações; GGUF local via Candle com mmap e carregamento em memória, modelos quantizados Qwen/Llama/Gemma/Phi em CPU, resolução explícita sem fallback silencioso; VM TinyML M35 com header canônico de 64 bytes, opcodes de tamanho fixo, validação completa da tape, orçamentos, assembler/trainer offline e fixtures sintéticas; parser zero-copy de envelopes MRE1 com ordenação canônica e regras de política.

Desafio
Unificar controle de memória em baixo nível, inferência local, transporte e limites de confiança sem criar um monolito.
Evidências
Rust 2021 · no_std · Candle · GGUF · M35 VM · MRE1 · Wasm · Axum · cryptography · CI architecture gates
03Estudo de caso privado

C++ · PYTHON · AGENTE LICENCIADO DE SISTEMAS

ESTH — Enterprise Scripting & Telemetry Host

Cliente licenciado + agente + API cloud para scripting e telemetria contra um game client first-party autorizado, em VMs isoladas de laboratório. Separação em quatro planos: cloud FastAPI (licença, vínculo de dispositivo, sync com controle de ownership, catálogo, OffsetBundle v3 criptografado, ingestão de telemetria), GUI nativa (login, HWID, catálogo, sync, editor, supervisão do agente), serviço agente local (fila de execução, scheduler orientado a dados, snapshots de diagnóstico) e contratos versionados (framing IPC, schema OffsetBundle, sem endereços fixos nos binários). Entrega de configuração protegida por AES-256-GCM com manuseio em memória, bundles de curta duração e comportamento fail-closed. Abstrações Windows (ImGui/DX11, named pipes, supervisão por job) e macOS (painel Metal/Cocoa, Unix sockets).

Desafio
Manter licenciamento, entrega de configuração, execução e diagnóstico isolados, versionados e fail-closed entre plataformas.
Evidências
C++17 · CMake · FastAPI · Pydantic · AES-GCM · versioned JSON schemas · pytest integration tests · manual lab battery

IV / Segurança & Red Team

Capacidade ofensiva,
postura defensiva.

Pesquisa prática em segurança conduzida somente para educação, defesa e testes autorizados. O foco é compreender comportamento de sistemas operacionais, análise binária e de protocolos e detecção defensiva — não ferramentação operacional. Implementações sensíveis permanecem privadas; a discussão pública se limita a conceitos, limites e resultados defensivos.

  • Windows internals e análise binária em VMs isoladas — estudando telemetria para saber o que defensores devem registrar
  • Revisão de protocolos e comportamento de apps, com avaliações de API orientadas por hipóteses e autorização explícita
  • Fundamentos de análise de malware: telemetria de loaders, padrões de IPC criptografado, persistência e detecções
  • Hábito de detection engineering: reproduzir comportamento suspeito com segurança e escrever o alerta ideal

Todo trabalho sensível permanece privado. Discussões externas limitam-se a conceitos, limites de escopo e resultados defensivos.

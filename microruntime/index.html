SANITIZED / ARCHITECTURE LEVEL

Micro Runtime runs AI within hard limits.

A modular Rust runtime for constrained environments. Numeric model output becomes bounded actions, tiny models stay inside declared budgets, and artifact parsers remain separate from trust decisions.

01 / AUTHORITY

Decision plane, not autopilot

A minimal TokenEngine returns numeric tokens. A bridge maps model tokens to dispatch tokens, then a fixed one-shot dispatcher invokes a closed HostOp handler. Probabilistic output never receives ambient authority.

model_token -> dispatch_token -> HostOp
dispatcher: one-shot / 256 slots / closed enum
02 / LOCAL MODEL

Explicit model resolution

Memory-mapped or in-memory model loading, quantized CPU inference, constrained decoding, and no silent fallback when a model is missing.

MODEL=/models/local.gguf
missing model => None
act budget => 32 digits
03 / TINYML

M35 VM

A canonical header and fixed-length opcodes are fully validated before execution. The VM uses int8 operations, no heap, no floating point, and hard operation and arena budgets.

HEADER 64B / MAX_OPS 4096
MAX_ARENA 16MiB / END required
04 / FORMAT

MRE1 envelopes

Canonical ordering, bounded records, reserved fields, and zero-copy borrowed views. Signature and counter trust stays in bootstrap code, not in the parser.

05 / MEMORY

Memory discipline

A page-based allocator, sharded heap, ephemeral scopes, read-only maps, and caller-buffer scrubbing make resource and lifetime decisions visible.

06 / PUBLIC BOUNDARY

Deliberately excluded

No weights, keys, certificates, private source, transports, kernel code, command infrastructure, or evasion material. This is an original explanation of safe concepts, not a runtime release.

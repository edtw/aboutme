01 / WHAT IT IS

An operator platform

An endpoint agent plus a command-and-control plane for authorized red-team work, with an operator HMI and one binary for Linux, macOS, and Windows. I designed the architecture, the tasking model, and the security boundaries.

02 / CONTROL PLANE

Tasking with identity

Operators issue typed tasks over mutual TLS, agents are pinned to site certificates, and every instruction, result, and decision lands in the audit trail. Nothing depends on a shell or an implicit channel.

operator -> control plane -> agent
identity: certificate + pinned PKI
03 / LOCAL AI

A model that cannot act alone

Quantized GGUF on CPU and a tiny INT8 model VM give the agent local decision support with no cloud. A capability broker authorizes each proposed action, so probabilistic output never receives ambient authority.

model_token -> dispatch_token -> HostOp
one-shot / 256 slots / closed enum
04 / BOUNDARIES

Strict everywhere else

A closed task ISA, isolated workers with no shell, hard memory and operation budgets, sealed weights, and zeroization on sensitive buffers. Powerful under authorization, fail-closed everywhere else.

05 / RED TO BLUE

Emulation to detection

I run the platform for adversary emulation in isolated labs, then turn what it produces into telemetry, detections, and hardening. Offense and defense share the same evidence, and only authorized scopes.

06 / SKILLS SHOWN

What this proves

Low-level Rust, memory and allocator design, PKI and secure transport, protocol design, cross-platform internals, local inference, and the discipline to gate every build with architecture checks.

07 / PUBLIC BOUNDARY

Architecture level

Private implementation, weights, keys, live transports, and privileged research stay off this page. I can walk through the architecture in interviews.

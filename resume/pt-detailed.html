Micro Runtime — RUST · ENGENHARIA DE SISTEMAS · RUNTIME LOCAL DE IA

Runtime modular em Rust 2021 para ambientes restritos. Arquitetura por features com no_std opcional, alocador customizado (páginas de 4 KiB, heap fragmentado, escopos efêmeros), SecureDispatcher fixo de 256 slots one-shot, IO com memory-map somente leitura, ISA fechada HostOp com session workers e validação automatizada da arquitetura no CI. Execução local de IA: trait TokenEngine separando decisões numéricas de ações; GGUF local via Candle com mmap e carregamento em memória, modelos quantizados Qwen/Llama/Gemma/Phi em CPU, resolução explícita sem fallback silencioso; VM TinyML M35 com header canônico de 64 bytes, opcodes de tamanho fixo, validação completa da tape, orçamentos, assembler/trainer offline e fixtures sintéticas; parser zero-copy de envelopes MRE1 com ordenação canônica e regras de política.

  • Construção de runtime Rust por features com suporte a no_std, alocação customizada e dispatch por capacidades one-shot
  • Implementação de execução local de IA: carregamento GGUF via mmap/em memória e VM TinyML sem heap, com orçamentos e validação
  • Criação de parsing canônico de envelopes, telemetria/diagnóstico e inventários de arquitetura no CI com limites de tamanho

ESTH — Enterprise Scripting & Telemetry Host — C++ · PYTHON · AGENTE LICENCIADO DE SISTEMAS

Cliente licenciado + agente + API cloud para scripting e telemetria contra um game client first-party autorizado, em VMs isoladas de laboratório. Separação em quatro planos: cloud FastAPI (licença, vínculo de dispositivo, sync com controle de ownership, catálogo, OffsetBundle v3 criptografado, ingestão de telemetria), GUI nativa (login, HWID, catálogo, sync, editor, supervisão do agente), serviço agente local (fila de execução, scheduler orientado a dados, snapshots de diagnóstico) e contratos versionados (framing IPC, schema OffsetBundle, sem endereços fixos nos binários). Entrega de configuração protegida por AES-256-GCM com manuseio em memória, bundles de curta duração e comportamento fail-closed. Abstrações Windows (ImGui/DX11, named pipes, supervisão por job) e macOS (painel Metal/Cocoa, Unix sockets).

RUST · DISTRIBUTED SYSTEMS · MESH / BLOCKCHAIN / COMPUTE · Spirix

Karma Network

Mesh network framework in Rust built around Proof of Antiquity blockchain, distributed computing, and agent capabilities. Three layers: blockchain (PoA consensus, Ed25519 wallets, hardware attestation, anti-Sybil nullifiers, on-chain marketplace, eclipse defense), mesh network (DHT overlay, mesh routing, relay forwarding, DAG state sync, peer discovery), and distributed compute (federated learning with FedAvg/DiLoCo, secure aggregation, differential privacy, pure-Rust ML inference with Candle, swarm coordination). 02Private case study

RUST · SYSTEMS ENGINEERING · LOCAL AI RUNTIME

Micro Runtime

Modular Rust 2021 runtime for constrained environments. Feature-gated architecture with optional no_std, custom allocator (4 KiB pages, sharded heap, ephemeral scopes), fixed 256-slot one-shot SecureDispatcher, read-only memory-mapped IO, closed HostOp ISA with session workers, and automated architecture validation in CI. Local AI execution model: TokenEngine trait decoupling numeric decisions from actions; local GGUF via Candle with memory-mapped and in-memory model loading, quantized Qwen/Llama/Gemma/Phi on CPU, explicit model resolution with no silent fallback; M35 TinyML VM with canonical 64-byte header, fixed-length opcodes, full tape validation, budgets, offline assembler/trainer and synthetic fixtures; MRE1 zero-copy product-envelope parser with canonical ordering and policy rules.

Challenge
Unify low-level memory control, local inference, transport, and trust boundaries without turning the runtime into a monolith.
Engineering evidence
Rust 2021 · no_std · Candle · GGUF · M35 VM · MRE1 · Wasm · Axum · cryptography · CI architecture gates
03Private case study

C++ · PYTHON · LICENSED SYSTEMS AGENT

ESTH — Enterprise Scripting & Telemetry Host

Licensed client + agent + cloud API for scripting and telemetry against an authorized first-party game client in isolated lab VMs. Four-plane separation: FastAPI cloud (license, device binding, ownership-gated sync, catalog, encrypted OffsetBundle v3, telemetry ingest), native loader GUI (login, HWID, catalog, sync, editor, agent supervision), local agent service (execution queue, data-driven scheduler, diagnostics snapshots), and versioned shared contracts (IPC framing, OffsetBundle schema, no hardcoded addresses in binaries). AES-256-GCM protected configuration delivery with in-memory handling, short-lived bundles, and fail-closed behavior. Windows (ImGui/DX11, named pipes, job supervision) and macOS (Metal/Cocoa panel, Unix sockets) abstractions.

Challenge
Keep licensing, configuration delivery, execution, and diagnostics isolated, versioned, and fail-closed across platforms.
Engineering evidence
C++17 · CMake · FastAPI · Pydantic · AES-GCM · versioned JSON schemas · pytest integration tests · manual lab battery
